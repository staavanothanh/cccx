# cccx release-gate scope

This file defines the reproducible scope for final Gates 24 and 25. Changing
the scope requires an explicit architecture decision; it must not be narrowed
only to make a failing release gate pass.

## Numeric coverage ownership

The aggregate `>=80%` line-coverage gate covers the nine standalone crates
whose implementation is owned by cccx:

- `cccx-protocol`
- `cccx-harness-cc`
- `cccx-harness-cx`
- `cccx-mode`
- `cccx-policy`
- `cccx-provider-gateway`
- `cccx-task-graph`
- `cccx-ux`
- `cccx-headless`

`cccx-cli` is the renamed upstream entry-point crate and is not counted as a
standalone owned crate. The cccx runtime surfaces inside upstream crates such
as `codex-core`, `codex-tui`, `codex-exec`, `codex-core-plugins`, `codex-api`
and `model-provider-info` remain mandatory release evidence. They require
focused positive and negative runtime tests, but the whole upstream crates are
not added to the numeric aggregate because doing so would measure unrelated
Codex code.

Canonical coverage command from `codex-rs/`:

```powershell
$env:CARGO_TARGET_DIR = "D:\cargo-targets\cccx-llvmcov"
cargo +1.95.0 llvm-cov `
  -p cccx-protocol -p cccx-harness-cc -p cccx-harness-cx `
  -p cccx-mode -p cccx-policy -p cccx-provider-gateway `
  -p cccx-task-graph -p cccx-ux -p cccx-headless `
  --summary-only --fail-under-lines 80
```

## Generated-source allowlist

Only these tracked generated roots are intentional:

- `codex-rs/app-server-protocol/schema/json`
- `codex-rs/app-server-protocol/schema/typescript`
- `codex-rs/hooks/schema/generated`
- `sdk/python/src/openai_codex/generated`

The app-server protocol schema roots are generated by
`codex-rs/app-server-protocol/src/schema_fixtures.rs`. The hooks and Python SDK
roots are checked-in generated interfaces from the upstream foundation. Any
new tracked `gen` or `generated` root fails the hygiene gate until this list is
reviewed deliberately.

Run the hygiene gate from the repository root:

```powershell
pwsh -NoProfile -File scripts/verify-cccx-repository-hygiene.ps1
```

The script also rejects tracked build/coverage outputs, cccx local state,
test homes, logs, temporary files and secret-like filenames. The only
secret-like filename exception is the exact public test-CA PEM fixture set in
`codex-rs/http-client/tests/fixtures`; PEM/key files anywhere else still fail.
